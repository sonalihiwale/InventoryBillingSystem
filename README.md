# Inventory Billing System

## About the Project
Inventory Billing System is a Java Swing desktop application used to manage inventory and generate bills.

## Features
- Add Items
- Update Stock
- Generate Bills
- Calculate Total Amount
- Display Remaining Stock
- Save and Load Inventory Data

## Technologies Used
- Java
- Java Swing
- Java Collections
- File Handling
- Eclipse IDE
